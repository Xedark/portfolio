01 — Structure d'accueil

Brest Métropole en bref

🏛️
Brest Métropole — Service Voirie
Collectivité territoriale regroupant 8 communes bretonnes depuis 2015. Le Service Voirie – Division Opérationnelle gère l'entretien du réseau routier, les arrêtés de circulation et l'occupation du domaine public sur tout le territoire métropolitain.

Le service est chargé de gérer les arrêtés de voirie — décisions administratives réglementant la circulation, le stationnement et l'usage de l'espace public. Chaque arrêté doit être correctement enregistré, géolocalisé dans des outils SIG (ArcGIS Pro et SIGEO) et diffusé aux services concernés.

🗺️
ArcGIS Pro
SIG professionnel d'Esri. Permet de créer, modifier et géolocaliser les arrêtés sur des couches cartographiques (points, lignes, surfaces).
🌐
SIGEO
Plateforme interne web de Brest Métropole. Centralise et partage les données géographiques entre tous les services, accessible via navigateur.
📄
Arrêtés de voirie
Décisions légales du Maire réglementant l'espace public : stationnement, travaux, zones 30, arceaux vélo, places PMR, etc.
🔄
Workflow projet → vigueur
Les arrêtés passent d'un état "projet" (en cours de validation) à "vigueur" (définitif et visible sur SIGEO) après vérification.
02 — Projets réalisés

Trois outils développés

En parallèle de la mission principale de mise à jour cartographique, j'ai développé trois outils pour moderniser et faciliter la gestion des arrêtés, dans la continuité du travail d'un précédent stagiaire.

🌐
Site internet de recherche des arrêtés
HTML · CSS · JS

Création d'un site web permettant de rechercher, consulter et gérer les arrêtés de voirie directement depuis un navigateur. L'objectif était de rendre la consultation plus rapide et intuitive pour les agents de Brest Métropole.

Le site est connecté à une base de données SQLite et affiche les données en temps réel. Il intègre un système de rôles utilisateurs (Admin, Modérateur, Utilisateur) avec des permissions différentes sur les données.

Recherche d'arrêtés par numéro NOARR (ex. : 019-2024-12-54)
Affichage tabulaire avec OBJECTID, NOARR, ÉTAT, NMFIC, IDRUE, TITRE, DT_SIGN
Gestion des utilisateurs et de leurs rôles (Admin / Modérateur / User)
Interface simple et accessible sans installation, via navigateur

⚠️ Ce site est connecté à une base de données test et non à la vraie base Brest Métropole, pour des raisons de confidentialité.

Script Python — Menu interactif
Python · SQLite · openpyxl

Développement d'un script Python avec menu interactif en ligne de commande permettant de gérer directement les arrêtés de voirie. Ce script s'inscrit dans la continuité du travail d'un précédent stagiaire et vise à préparer la transition vers le futur logiciel développé par la SIG de Brest Métropole, qui remplacera ArcGIS Pro.

Afficher les premières et dernières lignes du fichier d'arrêtés
Rechercher un arrêté par numéro NOARR
Remplacer une valeur dans une ligne existante
Créer un nouvel arrêté dans la base
Supprimer une ligne par NOARR

Le script interagit avec un fichier .xlsx (pour les tests) et est conçu pour être facilement adapté à une base SQLite ou à la future base de données de la SIG.

🗄️
Base de données SQLite de test
SQLite · SQL

Création d'une base de données SQLite pour tester le fonctionnement du script Python et du site web sans interagir avec les vraies données de Brest Métropole. SQLite est léger, sans serveur dédié, et stocke tout dans un seul fichier — idéal pour un environnement de développement et de test.

La base contient deux tables correspondant aux besoins du service :

Table arrete — OBJECTID, NOARR, ETAT, NMFIC, IDRUE, TITRE, DT_SIGN
Table users — USERID, NAME, SURNAME, ROLE (Admin / Moderator / User)

Cette base est reliée au site internet et sert de support de test pour le script Python. Elle simule la structure de la vraie base de données de Brest Métropole, permettant de valider les fonctionnalités avant déploiement.

init_db.py — Création de la base SQLite Python · SQL 
import sqlite3

conn = sqlite3.connect("db.sqlite")
cursor = conn.cursor()

# Table des arrêtés de voirie
cursor.execute("""
CREATE TABLE IF NOT EXISTS arrete (
    OBJECTID INTEGER PRIMARY KEY,
    NOARR    TEXT,
    ETAT     TEXT,
    NMFIC    TEXT,
    IDRUE    INTEGER,
    TITRE    TEXT,
    DT_SIGN  DATE
)""")

# Table des utilisateurs avec rôles
cursor.execute("""
CREATE TABLE IF NOT EXISTS users (
    USERID   INTEGER PRIMARY KEY,
    NAME     TEXT,
    SURNAME  TEXT,
    ROLE     TEXT  -- ADMIN / MODERATOR / USER
)""")

conn.commit()
conn.close()
03 — Mission principale

Mise à jour cartographique des arrêtés

La mission quotidienne consistait à intégrer les nouveaux arrêtés dans la base de données cartographique d'ArcGIS Pro, en respectant un workflow précis en plusieurs étapes.

1
Recherche de l'arrêté
Utilisation du script Python existant pour vérifier si l'arrêté est déjà présent dans la base (état projet ou vigueur) ou s'il doit être créé.
2
Placement des points, lignes et surfaces
Dans ArcGIS Pro, placement des balises cartographiques correspondant au type d'arrêté (stationnement interdit, zone 30, place PMR, arceaux vélo, sens unique…) sur la carte du territoire.
3
Association au numéro d'arrêté
Affectation des balises au numéro NOARR de l'arrêté et renseignement du chemin PDF dans la colonne LIBRU pour assurer la traçabilité documentaire.
4
Transfert projet → vigueur
Une fois les modifications validées, transfert de l'arrêté de la base "projet" vers la base "vigueur" — celle qui apparaît sur SIGEO pour tous les agents du service.

05 — Difficultés & solutions

Obstacles rencontrés

!
Lecture des arrêtés administratifs
Certains arrêtés étaient rédigés dans un langage juridique complexe et difficiles à interpréter sans contexte.
✓ Analyse détaillée et demande de précisions auprès des agents expérimentés du service.
!
Localisation précise sur la carte
Identifier l'emplacement exact d'un arrêté sur ArcGIS Pro nécessitait une bonne connaissance des rues et des outils SIG.
✓ Utilisation combinée d'ArcGIS Pro, de SIGEO (couche cadastre) et entraînement progressif jusqu'à une utilisation fluide.
!
Prise en main d'ArcGIS Pro
Logiciel riche en fonctionnalités mais complexe au départ, avec de nombreuses couches, outils et interactions à maîtriser.
✓ Consultation de la documentation officielle, observation des agents et pratique régulière.
06 — Bilan

Ce que ce stage m'a apporté

Ce stage au sein de Brest Métropole a été une expérience formatrice et concrète. J'ai pu découvrir le fonctionnement d'un service public de proximité et mettre en pratique directement les compétences acquises en BTS CIEL IR : Python, HTML/CSS/JS, SQL et bases de données.

Les trois outils que j'ai développés répondaient à de vrais besoins du service — faciliter la consultation des arrêtés, préparer la transition vers un futur logiciel interne, et tester les interactions avec une base de données. Ce n'était pas des exercices scolaires mais des projets utiles en contexte professionnel réel.

Au-delà du technique, ce stage m'a aidé à gagner en autonomie, à collaborer avec une équipe professionnelle et à comprendre les enjeux d'une collectivité territoriale. Il a également débouché sur un contrat CDD d'une semaine en juillet 2025, ce qui a confirmé la qualité du travail fourni.
