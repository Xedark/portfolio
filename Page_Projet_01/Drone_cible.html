01 — Contexte

Un besoin opérationnel réel

Ce projet s'inscrit dans le cadre du BTS CIEL option IR au lycée Vauban de Brest, en partenariat avec la Marine nationale et l'IRENAV (Institut de Recherche de l'École Navale).

La Marine souhaite disposer de drones cibles réalistes pour simuler les menaces modernes auxquelles ses équipages sont confrontés — notamment les attaques de petits navires rapides (skiffs) ou d'USV, de plus en plus utilisées, en mer Rouge notamment. Ces menaces sont peu coûteuses, rapides et difficiles à détecter.

L'objectif est de concevoir un prototype fonctionnel low-cost à base de composants du commerce (DIY), suffisamment fiable pour des essais réels, tout en restant économique car conçu pour être potentiellement détruit lors des exercices. Le projet sert également de preuve de concept pour évaluer la faisabilité de solutions low-cost en contexte militaire.

02 — Fonctionnement

Trois modes de pilotage

Le drone doit pouvoir basculer entre trois modes distincts selon la situation opérationnelle.

🕹️
Mode Manuel
Pilotage à distance par un opérateur via liaison radio LoRa. Le drone reçoit les commandes depuis la télécommande. Activé quand /robot_mode = 0.
🗺️
Mode Autonome GPS
Navigation sur un itinéraire prédéfini à partir de points de passage GPS (waypoints stockés en JSON). Activé quand /robot_mode = 1.
🎯
Mode Verrouillage
Détection d'une cible par caméra (YOLOv5) et suivi automatique. Activé quand /robot_mode = 2.

Un quatrième mode transversal — le Safemode (mode 3) — stoppe immédiatement tous les moteurs en cas de perte de communication ou de défaillance système.

05 — Code

Extraits commentés

Deux extraits représentatifs du travail développé, tirés des annexes du rapport.

Extrait 1 — Watchdog radio : surveillance du lien LoRa avec mécanisme heartbeat. Si aucun message n'est reçu en 3 secondes, le mode sécurité est déclenché.

radio_watchdog.py — check_watchdog() Python 
def check_watchdog(self):
    """
    Vérifie périodiquement l'état de santé de la communication.
    Si aucun message n'est reçu pendant plus de 3 secondes,
    une procédure de mise en sécurité est déclenchée.
    """
    # Calcul du temps écoulé depuis la dernière réception
    delta = (datetime.now() - self.last_msg_time).total_seconds()

    if delta > 3.0:
        self.get_logger().warn(
            f"Alerte : Perte de signal ({delta:.2f}s)"
        )
        # Création du message d'arrêt d'urgence
        msg = String()
        msg.data = "3"  # mode 3 = arrêt complet des moteurs

        # Publication vers le contrôleur moteur
        self.mode_publisher.publish(msg)

        # Réinitialisation pour éviter une boucle d'alertes infinies
        self.last_msg_time = datetime.now()

Extrait 2 — Navigation en mode verrouillage : correcteur proportionnel (P) à 20 Hz qui centre le drone sur la cible détectée par YOLOv5.

navigation_verrou.py — control_loop() Python 
def control_loop(self):
    """Boucle de contrôle (20 Hz) : centre le drone sur le bateau détecté."""
    twist = Twist()

    # Sécurité : si le mode verrou (2) n'est pas actif → stop
    if not self.locked or not self.last_detection:
        self.cmd_pub.publish(twist)
        return

    # Coordonnées du bateau détecté par YOLOv5
    boat = self.last_detection["boats"][0]
    center_x = float(boat.get("x_min", 0.0)) + (float(boat.get("width", 0.0)) / 2.0)

    # Erreur = écart entre le centre du bateau et le centre image (320 px)
    error     = center_x - self.image_center_x
    Kp        = 0.002   # Gain proportionnel
    dead_zone = 20.0    # Tolérance pixels — limite les oscillations

    twist.linear.x = 0.6  # Avance constante vers la cible
    if abs(error) > dead_zone:
        twist.angular.z = float(-Kp * error)  # Correction angulaire P

    self.cmd_pub.publish(twist)

08 — Matériel

Équipements embarqués

🧠
Raspberry Pi 5
Cœur du système. Exécute ROS2 dans Docker, YOLOv5 en temps réel et la logique de navigation avec latence minimale.
📷
Webcam USB
Capture le flux vidéo de l'environnement marin. Frames analysées par YOLOv5 pour détecter les cibles.
📡
Antennes Wi-Fi x2
Retour vidéo longue portée vers le poste opérateur. Maintient la liaison watchdog même loin des côtes.
⚡
PCA9685
Contrôleur PWM 12 bits via I2C. Pilote le servomoteur de gouvernail et les moteurs avec précision.
🔋
L298N
Pont en H — interface de puissance batterie/moteurs DC. Protège la Raspberry Pi des pics de tension (Back-EMF).
⚙️
2 Moteurs DC + 1 Servomoteur
Moteurs DC = propulsion (linear.x). Servomoteur = gouvernail (angular.z) pour une direction précise à haute vitesse.
